# CTRL home — сайт парфюмерии

Кастомный статический сайт интернет-магазина парфюмерии **CTRL home** («аромат как кнопка состояния»).
Написан вручную на HTML/CSS/JS — без фреймворков и сборки. Дизайн: светлый Paper-холст, тёмные акцентные секции, кислотный лайм, неон-розовый, шрифты Space Grotesk + Space Mono + Manrope.

## Как открыть

- Быстро: открыть `index.html` двойным кликом в браузере.
- Правильнее (чтобы корректно работали относительные пути): запустить локальный сервер в папке проекта и открыть в браузере:
  ```
  python3 -m http.server 8000
  ```
  затем перейти на `http://localhost:8000`.

## Архитектура

Сайт многостраничный, но общие части не дублируются вручную, а собираются скриптами:

- **`site-chrome.js`** — вставляет общую **шапку**, боковое меню-шторку и **футер** в пустые placeholder'ы `<div data-site-chrome></div>` и `<div data-site-footer></div>`. Меняешь меню здесь — оно меняется на всех страницах сразу.
- **`page-data.js`** — все **данные**: товары (`PRODUCTS`) и контент разделов (`PAGES`). Страницы-разделы — это пустые «оболочки» `<main data-page="ключ">`, которые этот скрипт наполняет по ключу. Также рендерит корзину (`korzina.html`).
- **`menu.js`** — логика меню: открытие шторки, второй уровень (flyout, конфиг `SUBS`), подсветка активного пункта, корзина в `localStorage` для внутренних страниц.
- **`philosophy-molecule.js`** — интерактивная «молекула» на главной.
- **`styles.css`** — все стили одним файлом.

## Структура страниц

- `index.html` — главная: видео-хиро, коллекция, философия + молекула, промо-блок, «4 шага». (Содержит свою шапку/футер инлайн — см. «Известные моменты».)
- `catalog.html` — каталог всех ароматов.
- `sobrat-nabor.html` — конструктор набора (своя вёрстка).
- `korzina.html` — корзина (рендерится из `localStorage`).
- `account.html` — личный кабинет (заглушка).
- Разделы каталога (оболочки + данные в `page-data.js`): `parfumeriya.html`, `novinki.html`, `sprei-dlya-tela.html`, `super-aromaty.html`, `uhod-za-telom.html`, `svechi.html`, `dlya-stirki.html`, `merch.html`, `podarochnye-karty.html`, `rasprodazha.html`.
- Контентные: `o-nas.html`, `kachestvo.html`, `soobshestvo.html`, `dostavka-i-vozvrat.html`.

Папки: `images/` (фото товаров), `videos/` (`hero.mp4`), `brand-summary/` и `ctrl-home-design-brief.md` (ранние бренд-материалы). Актуальная дизайн-карта была перенесена из `CTRL home.zip` / `styles.css` из Downloads.

## Как редактировать частое

| Что нужно | Где менять |
|---|---|
| Товар (название, цена, ноты, фото) | `page-data.js` → `PRODUCTS` |
| Контент раздела (заголовок, карточки, списки) | `page-data.js` → `PAGES`, ключ = значение `data-page` страницы |
| Пункты меню, шапка, футер | `site-chrome.js` (+ продублировать в `index.html`) |
| Второй уровень меню (flyout) | `menu.js` → массив `SUBS` (новый объект = новый раздел) |
| Стили, палитра, шрифты | `styles.css` (палитра — в `:root` в начале файла) |

## Cache-busting (важно)

Файлы подключаются с версией: `styles.css?v=10`, `menu.js?v=6`, `page-data.js?v=5`. **При изменении файла поднимай номер `?v=` на всех страницах**, иначе у части посетителей останется старая версия из кэша браузера.
