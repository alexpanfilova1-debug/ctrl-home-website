# CTRL home — бриф для Claude Design (v2 · Gen Z)

Курс: современный графичный, энергичный, под Gen Z. Светлый холст + два ярких
акцента (лайм + неон-розовый). Идея бренда — «контроль состояния»: аромат как
кнопка, отсылка к клавише Ctrl.

Скопируй блок ниже целиком и вставь в Claude Design (claude.ai/design).

---

## ⬇️ Вставить в Claude Design

```
Собери дизайн-систему для бренда CTRL home — нишевая парфюмерия и ароматы
для дома и тела. Идея: «контроль состояния» — аромат как кнопка, которая
переключает тебя (фокус, спокойствие, подъём), отсылка к клавише Ctrl.
Аудитория — Gen Z. Тон: современный, графичный, смелый и энергичный,
без классической парфюмерной нарядности и без «AI-глянца».

ХОЛСТ И ЦВЕТ (используй именно эти значения):
- Основной холст светлый: Paper #F7F5EF (фон), Ink #1A1916 (текст).
- ДВА ярких акцента: кислотный лайм #CCF400 и неон-розовый #FF2D9E.
- Тёмные секции-акценты на Ink #1A1916 (hero, блок товара) для контраста.
- Расширь до состояний (hover / active / disabled / focus) и семантики
  (успех / ошибка / инфо) в этой гамме; нейтральная шкала на базе #1A1916.

ТИПОГРАФИКА:
- Заголовки — Space Grotesk, крупно и «чанково», плотный трекинг.
  Типографика — главный носитель характера.
- Детали (цены, лейблы, бейджи, слово CTRL, артикулы) — Space Mono,
  как отсылка к клавиатуре и команде.
- Текст — Manrope.
- Дай шкалу размеров (display / H1–H4 / body / caption) с line-height и tracking.

СЕТКА: spacing 4/8/12/16/24/32/48/64; контейнер 1200–1280px; 12 колонок.

КОМПОНЕНТЫ:
- Кнопки: основная (заливка неон-розовый, тёмный текст), вторичная (контур
  Ink), призрак; все состояния + тактильный отклик на :active.
- Карточка товара: фото + название (Space Grotesk) + цена (Space Mono) +
  бейдж-режим (например CTRL+FOCUS).
- Поле ввода: label сверху, текст ошибки снизу.
- Бейджи статуса: новинка / скоро / лимитка / распродажа — лайм или розовый.
- Хедер с навигацией, футер.
- Фирменный мотив: клавиша-кейкап со знаком ⌃ и лейблы CTRL+СОСТОЯНИЕ.

ПРИМЕР ЭКРАНОВ: каталог и карточка товара на светлом холсте
с одной тёмной акцентной секцией.

ЖЁСТКИЕ ПРАВИЛА (чтобы было современно, а не «AI-шно»):
- Два акцента используем дисциплинированно: много воздуха и белого,
  неон — на акценты, CTA, выделения и статусы; два неона не дерутся в одном
  элементе. Заливки плоские, без свечений и размытий.
- Контраст текста: на лайме — Ink; на розовом — почти чёрный или белый
  (проверь читаемость), не серый.
- Чёрный только #1A1916, не #000.
- Hero и секции — НЕ центрованный текст: сплит-экран или левое выравнивание
  + крупное фото.
- Никаких рядов из 3 одинаковых карточек — зигзаг, бенто или гор. скролл.
- Иерархия через размер / вес / цвет; крупная типографика как приём.
- Фото — настоящие предметные кадры флаконов и текстур с вкраплениями
  акцентных цветов; не сток, не Unsplash.
- Тексты конкретные, без «Elevate / нового поколения»; цифры живые.
- Обязательно состояния: загрузка (скелетоны), пусто, ошибка.
- Лёгкие микро-анимации (Y2K-цифровой характер) через transform / opacity.
```

## Шаги

1. В Claude Design создай проект **CTRL home**.
2. Вставь блок выше как первый запрос, запусти генерацию.
3. Пришли мне результат (скриншот / текст: токены, компоненты).
4. Дальше переносим токены в `styles.css` и применяем к страницам.

## Зафиксированные токены

| Роль | Значение |
|---|---|
| Холст (Paper) | `#F7F5EF` |
| Текст (Ink) | `#1A1916` |
| Акцент 1 — лайм | `#CCF400` |
| Акцент 2 — неон-розовый | `#FF2D9E` |
| Заголовки | Space Grotesk |
| Детали / цены / лейблы | Space Mono |
| Текст | Manrope |
| Мотив | клавиша `⌃`, лейблы `CTRL+СОСТОЯНИЕ` |

## Что меняем относительно текущего сайта

- Убрать Prata (serif) и золото `#9a7b4f` — они тянут в «классическую парфюмерию».
- Заменить ряды из 3 одинаковых карточек на зигзаг / бенто.
- Убрать фото с Unsplash, поставить свою съёмку.
