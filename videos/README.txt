Папка для видео сайта CTRL home
================================

Сюда клади видеофайлы для сайта (например, ролик для главного экрана).

Рекомендации для видео на главный экран (hero):
- Формат: MP4 (кодек H.264) — открывается во всех браузерах.
  По возможности добавь ещё версию WebM для меньшего веса.
- Имя файла: hero.mp4 (так его проще подключить).
- Без звука / короткая зацикленная петля 5–15 сек смотрится лучше всего.
- Размер: желательно до 5–8 МБ, разрешение 1920×1080.

Как добавить:
1. Положи файл сюда → videos/hero.mp4
2. Напиши мне «подключи видео на главный экран» — я заменю
   картинку на видео в index.html.
